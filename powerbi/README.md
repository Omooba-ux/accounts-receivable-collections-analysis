# Power BI Dashboard

## Overview

The final stage of this project involved transforming the analysed financial data into an interactive Power BI dashboard.

The dashboard was designed to provide visibility into accounts receivable performance, payment behaviour, ageing patterns, and customer exposure.

---

# Dashboard Objectives

The dashboard was developed to help answer:

- What is the overall receivables position?
- How much invoice value remains outstanding?
- Which invoices represent collection risk?
- Which customers contribute the highest exposure?
- How does receivable risk vary across customer segments and industries?

---

# Dashboard Pages

## Page 1: Accounts Receivable & Collections Analysis

Key areas covered:

- Total Invoice Value KPI
- Outstanding Receivables KPI
- Collectible AR KPI
- Seriously Late Exposure KPI

- AR Ageing Analysis
- Industry Exposure
