# SQL Analysis

## Overview

The SQL stage involved moving the prepared invoice and customer data into MySQL to perform structured analysis and validate financial metrics.

The objective was to create a reliable database environment for analysing accounts receivable performance, payment behaviour, and customer exposure.

---

# Database Structure

The analysis used two main tables:

## Invoice Table

Contains transactional information including:

- Invoice details
- Invoice values
- Payment dates
- Payment status
- Receivables information

## Customer Table

Contains customer-level attributes including:

- Customer ID
- Industry
- Customer size
- Region

---

# SQL Analysis Performed

The SQL workflow included:

## Data Validation

- Checking record counts
- Reviewing data consistency
- Validating imported records

## Receivables Analysis

- Total invoice value calculation
- Outstanding balance analysis
- Payment performance analysis
- AR ageing calculations

## Customer Analysis

- Customer exposure analysis
- Industry-level comparison
- Customer ranking by outstanding balances
